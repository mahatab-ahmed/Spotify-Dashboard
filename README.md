🎵 Spotify Music Insights Dashboard – Power BI Project
📘 Overview
This Power BI project presents an interactive Spotify Music Insights Dashboard that analyzes music streaming data across various dimensions including track popularity, artist trends, and audio characteristics like energy, danceability, and valence. It empowers users to explore patterns in user preferences and track performance over time.

🎯 Objectives
Visualize total streams and top tracks across years and genres

Analyze track audio characteristics (danceability, energy, valence)

Identify popular artists, keys, and release years

Discover trends in streaming behavior and audio features

📂 Data Sources
Spotify Top Tracks data

Audio features: Danceability, Energy, Valence, Acousticness, Speechiness, Key

Track metadata: Artist name, Track name, Release year, Streams

📊 Dashboard Features
🔢 KPIs:
Total Streams (383bn)

Danceability, Energy, and Valence percentages (Gauge visuals)

📅 Filters/Slicers:
By Track Key, Release Year, and Artist Name

📈 Visuals:
Top Tracks by Streams – Visualize tracks like Shape of You, Sunflower, One Dance, etc.

Track Streams over Time – See streaming growth by release year

Popular Artist by Track – Ed Sheeran, Taylor Swift, Eminem, BTS, etc.

Track by Key – Most popular keys like C#, G, F, etc.

Speechiness & Acousticness – Scatter plot for analyzing spoken-word vs. acoustic characteristics

Drag Characteristics Comparison – Custom comparison of audio traits

🧩 Treemap:
Streams by Released Year – Highlights popularity and release volume by year

⚙️ Technologies Used
Power BI Desktop

Power Query for data transformation

DAX for calculations and measures

Custom Visuals for advanced interactivity
